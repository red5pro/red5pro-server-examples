Red5 Pro Server Examples
===
Within this repository you will find several examples used in creating the WebApps provided with the [Red5 Pro Server](https://www.red5.net/red5-pro/low-latency-streaming-software/)

The common-demo application is a simple example of using the Red5 Pro Common library in your own projects.

## Red5 AI Skills

Use the **Red5 AI skills** to help your AI coding assistant build real-time video applications with Red5 Pro and Red5 Cloud, with guidance grounded in Red5 documentation. [Download the skill from GitHub](https://github.com/red5pro/red5pro-skills) or install it by running `npx red5pro-skills` in your terminal.
